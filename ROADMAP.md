# Neon Player — дорожная карта

25 ноября 2026. Отдельная полная Android-версия на libmpv; исходная Lite 0.6.0 и Windows не изменяются. Публикация на GitHub не разрешена. Интерфейс — собственная реализация выбранных рендеров, без копирования кода Plllay с неуточнённым LICENSE.

## 0.1 — рабочая основа и основные функции

Статус обновлён 25 ноября 2026, сборка 0.3.7. `[x]` означает, что функция реализована в текущей версии; проверки на физических устройствах и реальных серверах отмечены отдельно ниже. Реализация и проверки на устройствах отмечены раздельно.

- [x] libmpv: локальные файлы и прямые URL, аппаратное декодирование, дорожки/субтитры, скорость, обработка ошибок. Позиция сохраняется в текущем сеансе при смене конфигурации; продолжение после перезапуска относится к истории ниже.
- [x] Собственный графитовый интерфейс из рендеров: управление справа/слева или по двум сторонам, вертикальная лента перемотки; видео не перекрывается там, где хватает свободных полос.
- [x] Блокировка касаний: автоблокировка через 5 с после скрытия управления, двойной тап для разблокировки; для пульта сохранено удержание OK. Подсказка находится в прежней области управления.
- [x] Телефон/планшет/Android TV: автоматический режим и ручное переключение, фокус и D-pad; смена интерфейса пультом.
- [x] Масштаб видео в процентах; 100% — вписанный целый кадр. Сохранение по экрану, размерам доступного окна и ориентации, включая сложенную/раскрытую раскладушку. Размеры интерфейса не зависят от выбранного масштаба видео. Масштаб UI 80–140% настраивается отдельно от видео.
- [x] Неоновая уточка: адаптивная иконка телефона с безопасной зоной маски и отдельная плашка Android TV 16:9 с названием Neon Player.
- [x] TorrServer: адрес/авторизация, библиотека, файлы, поток, добавление magnet и torrent-ссылок через API; поиск серверов в LAN.
- [x] Поиск торрентов: по умолчанию https://jac.red, редактируемый адрес и API-ключ; ошибка сервиса не заменяется пустым результатом. Действия «Воспроизвести через TorrServer» и «Добавить в TorrServer».
- [x] SMB: гость/логин/пароль/домен, общие папки и файлы, перемотка.
- [x] FTP: каталоги, файлы, логин/пароль, пассивный режим и перемотка.
- [x] SFTP: каталоги, файлы, логин/пароль, проверка ключа SSH-сервера и перемотка.
- [x] Подсветка полос: отключение, режимы, яркость, мягкость границы, размытие; экономия ресурсов на телефоне.
- [x] БАГ: при включении подсветки полос видео растягивается на весь экран вместо появления подсветки в свободных областях. Исправить геометрию ambient-вывода: размер, пропорции, выбранное вписывание, процентный масштаб и положение основного кадра должны оставаться такими же, как при выключенной подсветке; размытое/светящееся заполнение рисуется только вокруг него. Проверить aspect override, размер выходного shader-canvas и координаты выборки центрального изображения; не считать успешную компиляцию шейдера проверкой правильного изображения. Сравнить до/после на широком видео в портретном и горизонтальном окне, вертикальном ролике, компоновке по краям и сдвиге вверх/вниз; отключение подсветки должно полностью восстанавливать обычную геометрию.
- [x] Шейдеры ПК: RAVU, FSRCNNX/KrigBilateral, профили 480p/720p, Anime4K Fast/HQ, сброс; тяжёлые профили включаются вручную.
- [x] Для каждого шейдера/профиля в настройках добавить краткую понятную карточку: что улучшает, для какого контента/исходного разрешения лучше подходит, примерная нагрузка («Лёгкий», «Средний», «Тяжёлый») и возможные побочные эффекты. Описание должно соответствовать реальной цепочке профиля; нагрузка сравнительная и зависит от GPU/разрешения, не выдавать её за измеренный FPS. До применения можно прочитать описание и вернуться к списку.
- [x] Исправить навигацию настроек: после изменения значения оставаться в текущем разделе либо возвращаться к его родителю, сохраняя положение списка. «Назад» и стрелка в шапке поднимают на предыдущий уровень настроек, а не сразу на главный экран. Выход из всех настроек возвращает туда, откуда они открыты: к текущему видео или библиотеке. Применение настроек не перезапускает видео и не сбрасывает позицию/паузу.
- [x] Завершить единый раздел «Расположение видео и управления»: объединить положение кадра и панелей в одном дереве с ветками «По горизонтали» (управление слева/справа/по краям, кадр между панелями) и «По вертикали» (кадр сверху/по центру/снизу, управление в свободном пространстве). Показывать выбранный вариант и обеспечить возврат к корню раздела. Выбор горизонтальной компоновки снимает прежний вертикальный сдвиг, чтобы он не скрывал результат. Не оставлять дублирующие разрозненные пункты в других настройках; ориентация экрана и режим вписывания остаются отличимыми действиями.
- [x] Шестерёнка во время воспроизведения открывает полноценное красивое меню Deck по выбранным рендерам: графитовые поверхности, читаемые карточки/иконки, бирюзовый акцент, плавное открытие и переходы. Это меню поверх/рядом с текущим просмотром, а не переход на главный экран. В нём обязательно доступны «Интерфейс» (Авто / Телефон-планшет / Android TV), «Подсветка полос» (выкл./режим/яркость/размытие/мягкость границы), расположение видео и управления, вписывание/масштаб, шейдеры, скорость и дорожки. Переключение интерфейса и подсветки применять к текущему просмотру без перезапуска; поддержать пульт, возврат по уровням и блокировку касаний. Единая точка открытия настроек для одно- и двухсторонней, компактной и TV-компоновки; не подменять шестерёнку сокращённым техническим списком без этих пунктов.

- [x] SponsorBlock: включение/категории/пропуск, явная привязка к ID YouTube; не применять к произвольному фильму без соответствия.
- [x] Сборка APK для arm64-v8a, armeabi-v7a и x86_64; базовые JVM-тесты проходят (в alpha.6 — 9).

## 0.1.0-alpha.3 — Deck и удобство открытия

- [x] Подготовить два рендера главного меню и результатов поиска. Пользователь выбрал Deck; Glass отложен. Исходные изображения и промпты — docs/design/.
- [x] Главный экран Deck: компактная шапка с уточкой, продолжение просмотра, плитки источников, состояние домашней сети, избранные папки и нижняя навигация. Меню/списки — собственные экраны с отдельными карточками.
- [x] Результаты торрентов: разделённые карточки, отдельные параметры/трекер, кнопки «Смотреть»/«TorrServer», сортировка по сидам/размеру/названию, фильтры качества из названия и трекера. Постеры из рендера пока не загружаются.
- [x] Единое поле поиска торрентов с подписью «Название, код Кинопоиска или IMDb либо ссылка». Принимать обычное название, kp123456, tt1234567 и ссылки Кинопоиска/IMDb. Ссылки kinopoisk.ru/film/<id>/ и /series/<id>/ преобразовывать в kp<id>; imdb.com/title/tt<id>/ — в tt<id>. Пример пользователя: https://www.kinopoisk.ru/series/178707/?socialAlias=MjQ3NDAzOTg%3D → kp178707. Query-параметры и фрагменты не влияют на ID, готовые коды сохраняются; обычный текст ищется по названию. Показывать распознанный код и передавать запрос в настроенный источник поиска. Проверять домен/путь/формат ID; не считать произвольное число кодом без выбранного источника. Неподдерживаемые ссылки объяснять явно. Отдельно сверить поддержку и формат TMDb (tmdb...), показанного в референсе, перед добавлением; не путать с IMDb.
- [x] Автопоиск SMB/TorrServer в фоне при запуске и при открытии сетевого раздела, повторный поиск вручную, кэш для текущей сети на сеанс. Проверять Wi-Fi/Ethernet, адрес самого устройства и loopback; FTP/SFTP остаются ручными.
- [x] Локальный TorrServe: если настроенный сервер на этом Android не отвечает, предложить открыть установленный ru.yourok.torrserve; после возврата повторить подключение. Не обращаться к закрытым сервисам, не запускать приложение для удалённого сервера. Требуется установленный/настроенный серверный модуль в TorrServe.
- [x] Собственный файловый раздел: папки с видео из MediaStore, количество и размер видео, доступ ко всем/выбранным видео, добавление папок через SAF, избранные папки. Сортировка папок по имени/дате/размеру; файлов — естественная/обратная/дата/размер.
- [x] Ручной поворот отдельной кнопкой независимо от системного автоповорота; настройка «По видео» по умолчанию, фиксированные горизонталь/вертикаль и системный режим. Учитывать rotate-метаданные; ручное переключение действует на текущий файл. На ATV ориентацию телефона не применять.
- [x] Исправить возврат ориентации после просмотра: если телефон держат вертикально, а плеер автоматически повернулся для широкого видео, при выходе из просмотра на главный экран, в проводник или библиотеку интерфейс должен снова стать вертикальным. Ограничение ориентации, выбранное «по видео», применять только к экрану воспроизведения; при выходе восстанавливать предшествующую политику ориентации интерфейса с учётом системного автоповорота/блокировки. При возврате к самому видео снова применять его ориентацию, сохраняя позицию и паузу. Проверить сценарии выхода кнопкой «Назад» и через меню, включённый/выключенный автоповорот, ручной поворот текущего видео; на ATV не включать телефонную портретную ориентацию.
- [x] Убрать диагностический текст про недостаток свободных полос; компактная панель с прогрессом и временем вместо него.
- [x] Привести боковое управление к рендерам: шапка NEON PLAYER, разделители, бирюзовая кнопка воспроизведения, отдельные скорость/очередь, временная метка на ленте. На низком экране часть действий уходит в «Дополнительно».
- [x] Заменить действие кнопки громкости в панели воспроизведения: вместо отдельного диалога переключать область вертикальной ленты перемотки на два вертикальных ползунка рядом — «Яркость» и «Громкость». Повторное нажатие/явная кнопка возврата возвращает перемотку. Сохранить компоновку выбранных рендеров без дополнительного перекрытия видео; показать иконки и текущие значения, поддержать касания, блокировку интерфейса и D-pad. Яркость менять для окна плеера, громкость — для воспроизведения; при переключении ползунков не менять позицию видео. Для компактного интерфейса без вертикальной ленты предусмотреть такое же доступное управление в свободной области.
- [x] БАГ/доработка вертикальной перемотки: сейчас нет видимого движения ползунка при прокрутке. Сделать явно движущийся бегунок на вертикальной шкале: его положение отражает позицию/длительность видео и плавно обновляется при обычном воспроизведении. При перетаскивании бегунок сразу следует за пальцем и показывает выбранное время; обновления от плеера не перехватывают его до завершения жеста. После отпускания выполнить перемотку и согласовать индикатор с фактической позицией. Кнопки ±10 секунд и пульт также двигают бегунок; корректно обрабатывать начало/конец, отмену жеста и неизвестную длительность. Сохранить визуальный стиль рендера, избегать неподвижной декоративной точки вместо реального ползунка.
- [x] Точная перемотка длинных видео: двухуровневое управление вместо одной грубой шкалы на весь фильм. Основной вертикальный ход — быстрый обзор всей длительности. Во время перетаскивания отведение пальца от шкалы в сторону видео уменьшает чувствительность: «Обзор» → «Точно» → «Очень точно»; точный режим также доступен удержанием бегунка и с пульта. Показывать выбранное время и активную точность. Привязку движения к секундам пересчитывать по длительности и доступной высоте: при фильме 90 минут точный режим должен позволять уверенно выбрать нужную минуту и уточнить позицию примерно до секунды, а не требовать попадания в один пиксель основной шкалы. При смене точности переопределять опорную точку жеста без скачка времени; фактический seek выполнять при завершении, предварительное время обновлять сразу. Проверить короткие клипы и фильмы 90/180 минут, масштаб UI и разные экраны; не добавлять неподтверждённые превью кадров. Общая шкала продолжает отражать абсолютную позицию, а увеличенная локальная шкала/метка показывает точную коррекцию.
- [x] Точная компоновка двухстороннего интерфейса «Видео по центру»: использовать приложенный пользователем рендер как эталон геометрии — узкая панель слева, целый кадр между панелями, узкая панель справа; графитовые поверхности, разделители и пропорции по референсу. Распределение функций ниже обязательно и имеет приоритет перед расположением старых значков на рендере:
  - Левая панель: управление воспроизведением (назад 10 секунд → воспроизведение/пауза → вперёд 10 секунд), кнопка плейлиста/очереди и кнопка выбора вписывания изображения (вписать, заполнить/обрезать, растянуть и другие доступные режимы). Кнопка вписывания не заменяется кнопкой поворота экрана: это разные действия.
  - Правая панель: вертикальная перемотка с текущим временем/длительностью; в той же области по переключению отображаются два вертикальных ползунка яркости и громкости. Здесь же располагаются скорость воспроизведения и настройки. Настройки — в верхней части панели, скорость — в нижней, как на референсе; центральная высокая область отведена перемотке/ползункам.
  - Сохранить доступную кнопку переключения «перемотка ↔ яркость/громкость» и возврат к перемотке. Не добавлять третью панель и не перемещать плейлист обратно вправо. Дорожки, блокировку и поворот оставить доступными через дополнительные действия, не нарушая заданное распределение основных кнопок.
  - Сверять реализацию с рендером и этим списком на каждом изменении компоновки; распределение реализовано в alpha.5; реальные размеры/фокус ATV ещё проверяются пользователем. При недостатке свободных полос использовать отдельную компактную компоновку, сохраняя выбранный режим для подходящего размера окна.


## Дополнения интерфейса и сетевых источников

- [x] Все иконки сделать немного более неоновыми: единая толщина/система значков, умеренный бирюзовый/пурпурный акцент и свечение, читаемость в маленьком размере; сохранять выбранную геометрию панелей по рендерам.
- [x] Анимации появления управления по касанию: несколько вариантов в настройках (плавное проявление, сдвиг, лёгкое масштабирование, без анимации), согласованное скрытие и переходы меню. Не терять первое нажатие и не блокировать пульт/касания во время анимации.
- [x] Подложка панелей управления: выбор «Чёрная» / «Прозрачная» в настройках. Панели преимущественно занимают свободное место вокруг кадра; обеспечить контраст иконок, не заполнять прозрачную подложку непрозрачными вложенными элементами.
- [x] Исправить чёрное превью «Продолжить просмотр»: извлекать/сохранять последний доступный кадр около сохранённого таймкода, обновлять при выходе/паузе. Не использовать постоянно первый чёрный кадр файла; при недоступном сетевом источнике показывать локально закэшированную миниатюру и понятную заглушку. Ограничить размер кэша и не блокировать главный поток декодированием.
- [x] Подтверждение выхода: системный «Назад» и жест навигации сначала возвращают по уровням; на корневом экране предлагают «Выйти» / «Остаться», не закрывают приложение сразу. Не перехватывать обычные жесты перемотки и системный Home; сохранять позицию перед выходом.
- [x] Уточка в шапке: небольшая анимация по нажатию и пасхалка после серии из 5–10 тапов. Сброс счётчика после паузы между тапами, без мешающих просмотру/звуку эффектов; доступна и с фокусом пульта.
- [x] SMB-избранное/закрепы: долгое нажатие на сетевой папке → «В избранное». Сохранять сервер, порт, общую папку и вложенный путь; нажатие на закреп сразу открывает нужную SMB-папку, не форму подключения. Доступны переименование и удаление закрепа; ошибки/недоступность сервера не удаляют его.
- [x] Привязка SMB-закрепов к Wi-Fi: в настройках папки/SMB выбрать текущую сеть; дома показывать домашние, на работе рабочие папки, непривязанные — везде. ### J.02 — мастер первого запуска

1. **Добро пожаловать.** Для чего приложение, поиск и отправка в Neon/другой плеер; «Начать настройку».
2. **Источник поиска.** «Онлайн» / «Локальная FileDB»; объяснение: онлайн не требует базы и парсеров на телефоне, локальный поиск работает по скачанному индексу, а получение свежих данных требует сети. Переключение позже доступно в настройках.
3. **Доступ к сети / VPN.** Напоминание включить VPN при недоступных источниках, кнопка открытия системных настроек VPN, «Проверить доступ», «Продолжить». Наличие VPN-интерфейса не выдавать за доступность всех сайтов: отдельные пробы выбранного сервера/источников. Не создавать VPN самостоятельно и не блокировать использование доступных ресурсов из-за отсутствия VPN.
4. **Онлайн-сервер** (ветка онлайн). Адрес, тип API, необязательный ключ, галка безопасного сохранения ключа, проверка подключения с понятной ошибкой. Недоступный `jac.red` можно заменить другим совместимым сервером. Не начинать загрузку FileDB в этом режиме.
5. **Парсеры / источники.** Выбор трекеров, фильтр категорий, статус поддержки/авторизации, настройки зеркала и прокси по необходимости. Для локального режима отдельно выбрать «Получать готовую БД/обновления» или «Парсить выбранные источники». Для онлайн-режима это фильтр доступных источников сервера, а не обещание управлять чужими парсерами. Недоступный/ещё не перенесённый парсер нельзя показывать как работающий.
6. **Хранилище и FileDB** (ветка локальная). Источник снимка/sync, папка и свободное место, дата/версия снимка, размер архива и оценка места после распаковки, Wi-Fi-only и обновления. Кнопки «Загрузить FileDB», «Импортировать существующую», «Позже». Если размер неизвестен — так и показать.
7. **Загрузка и подготовка.** Прогресс байтов/скорости, отмена/повтор и продолжение при поддержке Range/ETag; затем распаковка, проверка целостности и построение индекса отдельными стадиями. При прерывании не отмечать базу готовой. Сначала временный каталог/индекс, затем атомарная замена; прежняя рабочая база сохраняется до успеха.
8. **Обновления и запуск.** Частота, Wi-Fi/зарядка, расход места и очистка, ручной запуск, уведомление долгой операции. Итог выбранных настроек → «Готово». Не запускать все парсеры автоматически; явное подтверждение первой длительной операции. Вариант «Позже» честно сообщает, что локальная база ещё не готова, и предлагает онлайн.

- [ ] Реализовать мастер с доступным возвратом на предыдущий шаг, валидацией, пропуском неактуальных веток и сохранением состояния.
- [ ] Для чувствительных разрешений показывать системный запрос только при действии, которому он нужен; не просить все права на первом экране.
