# Настройки Neon Player 0.3.6

Разделители — заголовки, не дополнительные уровни навигации. Назад возвращает к предыдущему разделу. Выбранные значения отмечаются.

```text
Настройки
├─ Видео и апскейл
│  ├─ Вписывание и масштаб
│  │  └─ Вписать / заполнить / растянуть; масштаб видео
│  ├─ Шейдеры и апскейл
│  │  └─ Пресет → описание, нагрузка, применить
│  ├─ Подсветка полос
│  │  ├─ Выкл. / сияние от краёв / размытая сцена
│  │  ├─ Быстро / средне / тяжело
│  │  └─ Точки выборки, яркость, размытие, ширина перехода, сглаживание
│  ├─ Ориентация экрана
│  │  └─ По видео / горизонтально / вертикально / как в системе
│  └─ Повернуть экран [при просмотре]
├─ Звук и воспроизведение
│  ├─ Скорость воспроизведения
│  ├─ Аудио и субтитры
│  │  └─ Аудиодорожка / субтитры / добавить внешний звук или субтитры
│  ├─ Обработка звука
│  │  └─ Нормализация / ночной режим / усиление / лимитер / сброс
│  ├─ Пропуск интро и титров
│  │  └─ Режим / свои интервалы / возврат / главы / AniSkip
│  └─ SponsorBlock
│     └─ Вкл./выкл. / YouTube ID / категории / обновить сегменты
├─ Торренты и сеть
│  ├─ TorrServer и JacRed
│  │  ├─ TorrServer → адрес и авторизация
│  │  ├─ JacRed → адрес, API-ключ, тип API
│  │  ├─ Поиск торрентов
│  │  └─ Серверы в локальной сети
│  ├─ Сетевые папки и входы
│  │  └─ Закрепы по Wi-Fi / все закрепы / сохранённые входы
│  └─ Ссылки и YouTube
│     ├─ Справка по поддерживаемым ссылкам
│     └─ Обновить модуль YouTube (yt-dlp)
├─ Интерфейс и управление
│  ├─ Режим интерфейса → авто / телефон-планшет / Android TV
│  ├─ Расположение видео и управления
│  │  ├─ По горизонтали
│  │  │  └─ Справа / слева / по краям / по краям наоборот (play справа)
│  │  └─ По вертикали → видео сверху / по центру / снизу
│  ├─ Оформление управления
│  │  ├─ Анимация появления / подложка
│  │  ├─ Яркость и громкость / масштаб интерфейса
│  │  ├─ Стиль значков → DUO / LINE / SOFT / CUT / ORANGE
│  │  ├─ Направление перемотки → вверх или вниз вперёд
│  │  ├─ Автоблокировка
│  │  ├─ Тема приложения → Orange (по умолчанию) / Deck
│  │  └─ Иконка приложения → A1–A5 / B1–B5 / оригинальная
│  ├─ Раскладушка и Flex
│  │  └─ Автоматический Flex просмотра / отдельное главное меню Flex
│  └─ Блокировать касания [при просмотре]
├─ Файлы и библиотека
│  └─ Файловый проводник
│     ├─ Дерево папок / все видео / папки с видео
│     └─ NEW → количество дней или выключить
└─ Приложение
   └─ О приложении
      ├─ Версия и назначение
      ├─ Возможности
      ├─ Библиотека и локальные данные
      └─ Компоненты и лицензии → полные тексты
```

Поиск торрентов также доступен с главной через явно подписанную вкладку. Сортировка файлов и избранное находятся непосредственно в проводнике. Справка «?» доступна в окне ввода ссылки.
